# Comic Chat 2.1 color replacements

These 21 `_C.AVB` characters are color counterparts to the original
black-and-white Comic Chat characters. They are preserved in their original
version 1 file format and are decoded directly by the web client.

Source and instructions:
[The Unofficial MS Chat Add-On Site](https://www.phoenix-online-nexus.com/Nexus_21/index.htm#instructionsavb).
The restored page credits the original site to Steve Howland (Y-Guy).
